# FlowD Portfolio (ต้นแบบ)

เว็บรวมผลงานแบบมีฉาก 3D และระบบหลังบ้านสำหรับอัปโหลดผลงาน
ทำจาก Vite + three.js + GSAP ฝั่งหน้าเว็บ และ Node.js (Express) ฝั่งเซิร์ฟเวอร์ เก็บข้อมูลเป็นไฟล์ JSON ไม่ต้องติดตั้งฐานข้อมูล

## วิธีรัน

ต้องมี Node.js เวอร์ชัน 18.18 ขึ้นไป (แนะนำ 20 หรือ 22) ดาวน์โหลดได้ที่ https://nodejs.org

```bash
cd flowd-portfolio
npm install
cp .env.example .env      # แล้วแก้ ADMIN_PASSWORD ในไฟล์ .env
npm run dev
```

เปิด
- หน้าเว็บ: http://localhost:3000/
- หลังบ้าน: http://localhost:3000/admin/ (ถ้ายังไม่ได้ตั้ง .env รหัสเริ่มต้นคือ `flowd-admin`)

โหมด dev แก้โค้ดแล้วหน้าเว็บอัปเดตเองทันที

### ขึ้นเซิร์ฟเวอร์จริง

```bash
npm run build     # สร้างไฟล์หน้าเว็บไว้ที่ dist/
npm start         # รันเซิร์ฟเวอร์โหมด production ที่พอร์ต 3000 (เปลี่ยนได้ด้วย PORT ใน .env)
```

ใช้ได้กับ VPS ทั่วไปหรือบริการที่รัน Node ได้และมีดิสก์ถาวร (เช่น Railway, Render แบบมี disk, DigitalOcean)
**ต้องสำรองโฟลเดอร์ `data/`** เพราะผลงาน ข้อความ และไฟล์อัปโหลดทั้งหมดอยู่ในนั้น
ถ้าใช้ HTTPS ให้ตั้ง `HTTPS=1` ใน .env เพื่อให้คุกกี้ล็อกอินเป็นแบบ secure

## ใช้งานหลังบ้าน

- **ผลงาน**: กด “เพิ่มผลงาน” หรือลากไฟล์รูป/วิดีโอมาวางที่กรอบด้านบน (ไฟล์แรกเป็นภาพปก ที่เหลือเข้าแกลเลอรี)
  กรอกชื่อ หมวดหมู่ ปี ลูกค้า รายละเอียด แล้วบันทึก ผลงานขึ้นหน้าเว็บทันที
  ลากแถวเพื่อเรียงลำดับ, ติ๊ก “โชว์ในฉาก 3D หน้าแรก” เพื่อให้การ์ดลอยอยู่ในฉากหน้าแรก, ติ๊กออก “แสดงบนเว็บ” เพื่อซ่อนชั่วคราว
  ผลงานที่ยังไม่มีภาพปก ระบบจะสร้างภาพปกชั่วคราวจาก “สีประจำงาน” ให้
- **ข้อมูลเว็บ**: ชื่อเว็บ สโลแกน (หัวข้อใหญ่หน้าแรก) เกี่ยวกับเรา บริการ อีเมล เบอร์ ที่อยู่ โซเชียล
- **ข้อความติดต่อ**: ข้อความที่ส่งจากฟอร์มหน้า Contact

หมวดหมู่ที่พิมพ์ในผลงานจะกลายเป็นปุ่มกรองในหน้า Works อัตโนมัติ

## ปรับแต่งเป็นแบบ FlowD

- **สีและฟอนต์**: ตัวแปรบนสุดของ `src/style.css` (`--bg`, `--fg`, `--accent`, `--font-sans`, `--font-display`) และลิงก์ Google Fonts ใน `index.html`
- **สีฉาก 3D**: `BG` และ `ACCENT` บนสุดของ `src/gl/World.js` (ควรตรงกับ `--bg`, `--accent`)
- **โลโก้**: ตอนนี้เป็นตัวอักษรจากชื่อเว็บ เปลี่ยนเป็น SVG ได้ที่ `.hud__logo` และ `.gate__logo` ใน `index.html`
- **คอนเซ็ปต์ฉาก**: วงแหวนและพื้นน้ำอยู่ใน `#buildEnvironment()` ของ `World.js` จะเปลี่ยนเป็นโมเดล 3D ของเรา (.glb) ได้ด้วย `GLTFLoader` ของ three.js
- **เสียงจริง**: แทน `src/audio.js` ด้วยไฟล์เพลง (เช่นใช้ Howler.js)

## โครงสร้างไฟล์

```
server/index.js     เซิร์ฟเวอร์ + API + ล็อกอินหลังบ้าน
server/seed.json    ผลงานตัวอย่าง 8 ชิ้น (ใช้ครั้งแรกเท่านั้น)
data/               สร้างอัตโนมัติ: works.json, settings.json, messages.json, uploads/
index.html, src/    หน้าเว็บ
admin/              หน้าหลังบ้าน
```

อยากล้างข้อมูลตัวอย่าง: ลบผลงานในหลังบ้าน หรือหยุดเซิร์ฟเวอร์แล้วลบโฟลเดอร์ `data/` (จะกลับไปเป็นข้อมูลตัวอย่าง)

## เอาขึ้นโฮสต์ฟรีบน Render

1. สร้าง repository บน GitHub แล้ว push โค้ดนี้ขึ้นไป
2. เข้า https://dashboard.render.com/blueprints → **New Blueprint Instance** → เลือก repository นี้
3. Render จะอ่าน `render.yaml` แล้วถามค่า `ADMIN_PASSWORD` ให้ตั้งรหัสหลังบ้าน แล้วกด **Apply**
4. รอ build ประมาณ 2–4 นาที จะได้ลิงก์แบบ `https://flowd-portfolio.onrender.com`

ข้อจำกัดของแผนฟรี
- ถ้าไม่มีคนเข้า 15 นาที เซิร์ฟเวอร์จะหลับ คนแรกที่เข้าจะรอโหลดประมาณ 30–60 วินาที
- ดิสก์ถูกล้างทุกครั้งที่รีสตาร์ตหรือ deploy ใหม่ ผลงานจะกลับไปเป็นชุดใน `server/seed.json` (ภาพปกจาก YouTube/Vimeo ดึงใหม่ให้เอง)
  ถ้าจะใช้หลังบ้านเพิ่มงานจริงจัง ให้เพิ่ม Persistent Disk (แผนเสียเงิน) แล้วตั้ง `DATA_DIR` ให้ชี้ไปที่ดิสก์นั้น
